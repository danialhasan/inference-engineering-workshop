33–45 · Exercise 3

Four requests. One objective?

Edit exercises/ex03_concurrency.py.

python3 workshop.py check 3

Compare one request's wait with the whole group's finish.

Saved data does not execute your scheduler; the code check does.
Use --source live to measure your implementation.
Submit all jobs before waiting, bound max_workers, preserve order and propagate errors. Requested client concurrency is not observed model parallelism. The saved server allowed one model request at a time. Checkpoints verify overlap using mock jobs.
