OFFLINE INFERENCE ENGINEERING WORKSHOP SLIDES

This snapshot contains the current 72-slide dark-mode lecture and workshop deck.

The simplest backup:
Open inference-workshop.pdf in your PDF viewer. It needs no server, model, or internet.
The contents page links to each subsection; the PDF also has section bookmarks.

Interactive slides:
Open inference-workshop-offline.html in a normal desktop browser. All images,
styles and presentation scripts are inside that one file. Use arrow keys to
advance and F for fullscreen. The quiz reveals its answers when you advance.

If your browser or app blocks local HTML files:
- macOS: double-click Start-Mac.command (Python 3 must already be installed).
- Windows: double-click Start-Windows.bat (Python 3 must already be installed).
- Linux: run python3 serve.py from this folder.
The script opens a local address and keeps serving until you press Ctrl+C.
It does not download anything or expose the folder to the network.

External source links and the GitHub setup link still need internet when clicked.
They are citations; they are not required to display or navigate the slides.
The local inference lab is packaged separately and needs its model downloaded
before going offline.
